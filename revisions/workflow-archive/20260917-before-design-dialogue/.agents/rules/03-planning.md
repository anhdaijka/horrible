# Chapter preparation

Create an internal preflight.md, a situation-focused writing-brief.md and spoiler-safe character-context.md. There is no fixed fact count or required secret for each character.

Preflight verifies sources, outcomes, chronology, knowledge/reveal boundaries, durable state and factual dependencies. It also checks that the writer packet contains relationships, useful forms of address, everyday priorities and enough concrete context to write the scene.

The brief describes the situation, what people need from each other, what makes that difficult, the approved outcome and meaningful room for choices. Separate character motivation from instructions to the author. "Do not reveal the solution" is a knowledge boundary, not a psychological secret.

Character context selects relevant facts from profiles: family/social relationships, age/status where useful, habits of relating and ordinary commitments. Exclude future solutions and mandatory performance tics. Link provenance and allowed source sections. Minor situational motives can be execution options rather than new canon.

Resolve missing information from sources first. Ask only for a new material author choice. Existing design approval carries forward when the packet only restores established facts; label new exploratory choices honestly.
