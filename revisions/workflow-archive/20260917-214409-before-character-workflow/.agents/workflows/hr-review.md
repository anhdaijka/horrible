# /hr-review <chapter>

1. Read `.agents/skills/hr-source-review/SKILL.md` completely.
2. Choose `revised.md` if it exists and is the requested candidate; otherwise use `draft.md`.
3. Read the candidate from beginning to end before opening any planning or safety material.
4. Write `literary-review.md` from `templates/literary-review-report.md`.
5. If this is the same context that wrote or revised the candidate, mark `CONTEXT_INDEPENDENCE: COMPROMISED`; do not issue final PASS.

Do not edit the prose and do not audit canon in this pass.
