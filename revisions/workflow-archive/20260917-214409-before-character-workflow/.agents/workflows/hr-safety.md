# /hr-safety <chapter>

1. Read `.agents/skills/hr-source-safety/SKILL.md` completely.
2. Choose the same candidate version used for the current literary review.
3. Read `preflight.md`, the candidate, and only the authority sources needed to verify claims.
4. Write `safety-review.md` from `templates/safety-review-report.md`.
5. Classify each issue as a hard contradiction, unsupported real-world claim, unresolved author choice, or non-blocking observation.

Do not comment on beauty, voice, dialogue, pacing, imagery, word count, or preferred sentence technique.
