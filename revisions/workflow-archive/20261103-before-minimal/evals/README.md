# Novel OS Evaluations

Deterministic CI can test schema, continuity, lifecycle ordering, and operational artifacts. It cannot honestly guarantee that a model wrote a good novel chapter.

This folder therefore holds **manual/model evaluations** for the creative layer. `npm run lifecycle:test` copies golden artifacts and verifies deterministic state transitions; it does not run an authoring/review agent and is not evidence of literary competence.

- `horrible-workflow-regressions.md` — paired failure/valid cases for readiness, causal hinges, blind review, regression carry-forward and mutation boundaries.
- `fixtures/creativity-firewall/` — isolated non-canon packets for forward-testing writer context order and literary/safety triage.
- `fixtures/discovery-led-preflight/` — isolated ghost-horror/mystery locks for testing divergent scene discovery, scene ecology and reader-as-detective planning.
- `runs/` — dated observations from actual bounded agent runs; these are evidence for that run, not permanent certification.

Keep evals separate from canon. Passing an eval does not modify story state.
