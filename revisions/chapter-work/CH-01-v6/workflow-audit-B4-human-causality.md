# Workflow Audit — B4 Human Causality / Clue Exposure

Date: 2026-09-22
Scope: CH-01-v6 B3 shop-opening trial + generative workflow projection
Story-design impact: none
Canon impact: none

## Author finding

The B3 trial improved sentence/dialogue rhythm but still felt unnatural at the level of plot deployment: bà Lan/Khanh drifted toward investigation, death gossip behaved like evidence delivery, and scene mechanics appeared arranged to expose clues.

## Root causes

### 1. INVESTIGATOR_DRIFT
Reader-primary-detective was incorrectly leaking into character behavior. Non-investigators asked/verified facts useful to mystery without sufficient ordinary motive.

### 2. CLUE_EXPOSURE_ENGINE
The generative packet still contained a reader-detective field and evidence-visibility obligations. Writer therefore optimized scene causality around surfacing death detail → date → object → purchaser name → knowledge split.

### 3. SOFT_BEAT_SHEET_ECOLOGY
B3 ecology called concrete clue-trigger micro-events "optional affordances" (task reveals tag, extended gossip, overhearing/retelling). The model instantiated these suggestions as beats.

## B4 repair

- Preflight retains reader-detective architecture internally.
- QA retains clue visibility / cross-chapter dependency checks.
- Writing brief no longer contains a reader-detective checklist.
- Scene ecology contains processes, pressures, material conditions and information flows only.
- Character context contains ordinary motive baselines.
- Writer/Drafting use the counterfactual motive test:
  "If downstream mystery payoff vanished, would this person still have sufficient reason to do this now?"
- Reader may notice evidence no character investigates.
- Curiosity is not a universal repair.
- Failure Memory now records FM-011 / FM-012 / FM-013.

## CH-01 B4 compiler consequence

B4 does not change approved Q1–Q8 outcomes. It changes only how those outcomes are projected to Writer context.

C1/C2 remain B1.

B3 shop-opening trial remains a non-candidate B3 diagnostic.
Future generation uses B4 unless superseded.
