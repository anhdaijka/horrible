# Horrible

Vietnamese ghost-horror fiction workspace. Start at [AGENTS.md](AGENTS.md), [current session](author/session-state.md) and [current Case Zero](author/case-zero-current.md).

[Working together](docs/WORKFLOW.md) is the sole operating workflow: author intent → agent proposal → author choice → writing/self-edit → independent reading and logic check → author acceptance.

Codex/ChatGPT is the current author-selected primary writer and can manage sources, develop proposals and check logic. Writing requires no installation.

Story sources live in author/, plot/, characters/, worldbuilding/ and continuity/. Drafts live in revisions/chapter-work/; accepted chapters in chapters/. Research supports facts without becoming canon. Archived workflows and superseded packets are historical only.

Optional tooling: `npm run bootstrap`, `npm run story:check`, `npm run workflow:check`, `npm run tooling:check`. Export commands remain in package.json. These checks do not certify literary quality.

Uncommitted drafts and state are local until explicitly committed/pushed. See session-state for actual delivery status.
