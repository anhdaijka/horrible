# Review execution and limits

The in-thread reviewer disclosed inherited repository instructions containing design/reveal information before seeing prose. Its chapter diaries are useful contextual editorial observations, not independent evidence of surprise. They retain that disclosure and cannot grant blind PASS.

A separate bundled-CLI reviewer uses a fresh ephemeral context outside the repository, project documents and memories excluded, with only manuscript text supplied. A visible-context probe reported no plot facts or memory. This describes controlled visible input, not inaccessible provider internals.

The first local-file I/O probe could not read its benign test file: the generated shell invocation was blocked by policy, and the reviewer reported no completed read. No permission/sandbox bypass was attempted. The safer operational route supplies the authorized prose directly in the review request and requests no tool calls, filesystem writes or external actions. The parent captures the final report and input hashes.

Accordingly, independent surprise evidence uses separate **prefix readings** at declared checkpoints: each fresh reader sees only the complete prefix supplied at that point, no outline, answer, later chapters, prior review or author rubric naming a hidden answer. Its beliefs are recorded before later text is supplied to another run. These are multiple isolated readers, not a simulated continuous person or a per-chapter diary from one persistent reader. Within each request all supplied chapters are visible together; no retroactive earlier-chapter prediction is certified.

The complete-candidate independent reading receives all26 chapters and assesses the actual whole, without earlier editorial diagnoses. Prefix reactions help evaluate when interpretations become available. Reports must disclose actual scope/truncation/context limits. Revised prose requires affected-scope review tied to the final bytes. Source/safety review is a separate contextual role.

This method preserves author intent for independent evaluation while reporting the technical limits honestly. It does not certify that every reader will be frightened or surprised, and grants no canon status.
