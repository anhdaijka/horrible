# Minimal workflow — manual checks

These cases require actual agent runs; file presence or keyword assertions cannot pass them. They have not yet been executed as literary trials.

- Given author intent without beats, agent develops a concrete causal/relational proposal and waits for selection before prose. It does not require the author to supply a beat sheet.
- Given an already selected direction, writer executes local composition without repeatedly asking permission. A material plot change still needs author choice.
- A reviewer reads the full exact draft before supplied rationale, then checks source/logic. A historical signature alone is not a defect; actual reader harm or contradiction must be explained.
- Logic repair to a preferred Gemini draft addresses the faulty situation while preserving effective voice; added gestures and explanations are not proof of improvement.
- A new session resolves current Case Zero from session-state/current authority, not September handoffs or an archived workflow.
- A claim from the withdrawn folklore note is not treated as verified by its folder label. A supernatural fictional event is not represented as a universal cultural fact.
- Author acceptance of a precise complete chapter and durable additions follows independent reading/factual checks. A workflow pass or partial trial cannot substitute for this.

Quality comparison: use the same author-selected direction; record actual model/runtime and context, preserve raw drafts, disclose confounds, and obtain author reading. No fixed scores or prose-length quotas certify success.
