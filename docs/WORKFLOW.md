# Editorial workflow

The maintained role contracts live in .agents/rules/02-context.md through 05-review.md. The loop is:

1. Give a lightweight plot-following preflight from current sources: situation/destination, fixed truth, POV limits and only unresolved material choices.
2. Author supplies the beat sequence; agent develops inside its literary intent. If supplied already, do not ask again or choose a replacement route.
3. Write from sufficient bounded story context, then self-edit with separate QA.
4. Obtain a fresh literary reading and a separate safety review.
5. Revise at the scale the evidence warrants. Renew matching reviews.
6. Present the exact complete candidate and durable-state diff for author acceptance.
7. Promote approved prose/state and validate the changed continuity/registries.

## Preparation

Use existing packet interfaces from templates/. They organize story material, not a requirement to fill every heading. Source work may be deep while the initial author-facing preflight stays light. AWAITING_AUTHOR_BEATS is distinct from a new material author choice; approval of broad design is not a beat sequence. Develop alternatives only inside supplied beats. Rich people, material context and competing motives can support natural development; more mandatory events can make it rigid.

Execution choices inside approved boundaries proceed autonomously. Research source-resolvable facts. Only new consequential design choices need the author. Do not reopen resolved E1 or another approved design just to complete a questionnaire.

## Checks at the owning boundary

- Accepted story-state changes: run npm run story:check and applicable link/continuity checks.
- Route or skill-installation changes: run npm run workflow:check.
- Tooling changes: relevant tooling/lifecycle tests.
- Prose quality: full reading, independent review and author response.

No need to run all checks every turn or repeat an unchanged validation. Checks do not verify literary quality or truth entailment.

## Review and acceptance

Candidate.md is locator-only. Self-edit evidence and deltas go in writer-handoff.md. Independent review begins with complete prose before prior diagnosis; disclose contamination. A changed model in the same context is not a fresh reviewer.

Exact bytes and consequential authority must match reviews, acceptance and canon diff. A scene trial cannot be promoted as a complete chapter. Only approved durable state enters canon; external research alone does not establish story truth.

## Experiments and Git

A bounded non-canon trial is optional for a named uncertainty. Record inputs and a stopping condition; avoid an indefinite series of prompt patches. Preserve candidates and snapshot actual instructions before broad workflow changes.

Use semantic commits for meaningful recoverable states; a commit is not required for every agent action.
