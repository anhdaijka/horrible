# Research

Research is evidence, **not canon**.

Suggested flow:

```text
inbox → verified → author decision → canonical story file
```

Create subfolders as needed:

- `inbox/` raw notes/leads
- `verified/` checked facts with sources and uncertainty
- `sources/` local bibliographic/source notes (not large copyrighted copies)

Use `templates/research-note.md` for source-grounded research.

Do not treat Discovery documents as a substitute for verified research. Discovery can define what the story wants; `research/verified/` should support claims about what exists in real life.

Where a verified note labels something as `family-specific fiction`, `low confidence`, or `pending author approval`, do not generalize it into a Vietnamese cultural rule.
