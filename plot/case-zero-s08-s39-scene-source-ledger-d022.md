4. Does this scene have a live material/social task independent of puzzle delivery **and** a concrete causal consequence for plot/character/motif? D-019 forbids unrelated rural-life mini-novels that exhaust page count for no mystery payoff.
5. Is the horror an individually distinct human vulnerability (labor / care / authority / post-truth survival) rather than a spooky sound quota? Real black cat jump is an event but false cause.
